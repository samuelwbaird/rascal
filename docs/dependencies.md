# Third party dependencies

Each dependency is declared in its own file in [`deps/`](../deps), downloaded at a pinned version, checked against a sha256, and compiled into the executable. `make info` lists the versions, and `require('rascal.build').dependencies` reports them at run time. Each one's licence is collected in `LICENSES.txt`, which is included with every release and generated by `make licenses`.

To add another, see [Adding dependencies](technical/adding-dependencies.md).
